# Компактные панели Codex

Исходник — [style.css](../code/style.css).  
Изменения файла помощник автоматически применяет к открытым окнам C1/C2.

## Размеры

- Левая полоса навигации: 32 CSS px вместо 52; её кнопки — 28 CSS px.
- Верхняя строка меню: 26 CSS px вместо 36. Штатное меню и область перетаскивания окна сохраняются.
- Шапка Codex над New chat: 30 CSS px вместо 52; строка New chat — 22 CSS px вместо 30.
- Строки папок, проектов и чатов: 18 CSS px вместо штатных 30.
- Шрифт строк: 12 CSS px, межстрочный интервал — 14 CSS px.
- Отступ уровня дерева: 14 CSS px.
- Убраны дополнительные разделители и вертикальные padding списка чатов проекта.
- Кнопки и иконки ограничены высотой строки.

Zoom приложения остаётся 140%; модуль не меняет его настройку. Правила ограничены внешними панелями, сайдбаром и собственными элементами Folders. Основной текст чата не уменьшается.

Внешние размеры задают `--cui-edge-toolbar`, `--cui-rail-width` и `--cui-header-height` в первом правиле CSS. Высота папок задаётся `--cui-row`, отступ — `--cui-indent`, высота штатных строк — `--height-token-row` и `--height-token-nav-row`. При изменении высоты согласуйте размеры кнопок и заглушек ниже по файлу.

## Projects без Recents

Recents скрыт вместе со своим контейнером, поэтому он не оставляет пустого места в раскладке и его чаты не попадают в обход клавишей Tab. Projects занимает освободившуюся высоту общей области прокрутки. При раскрытии длинных веток используется штатная прокрутка сайдбара. Чаты и их принадлежность проектам не изменяются.

Эти правила общие для C1/C2. Закрытый профиль получает их при следующем запуске, открытые окна — автоматически при сохранении CSS.

## Проверка после изменения

С 19 октября 2026 года панели действий у папок и проектов не появляются при наведении; действия открываются правым кликом. Стартовая иллюстрация `home-icon` и заголовок «What should we build…» скрыты, а их родительская область больше не растягивает пространство над композером. Правила действуют в C1/C2.

Всплывающие карточки боковой панели (`[role=tooltip][data-overlay-owner=slate-sidebar]`) скрыты вместе с областью перехвата указателя. Явно открываемые меню и диалоги сохраняются. Диалоги выбора расположения Folders центрируются и занимают `100dvh - 16px`; дерево с прокруткой заполняет оставшуюся высоту flex-контейнера без ограничения в 280 px. Заголовок и кнопки остаются видимыми, полный путь расположен под деревом, отступ уровня — 18 CSS px. В диалоге назначения проекта кнопка новой папки перенесена в общий нижний ряд, а повторная подпись «Расположение» оставлена только для средств доступности. При текущей высоте окна дерево занимает 80,86% его высоты.

Проверьте папки, раскрытый проект с чатами, пустой проект, наведение и клавиатурный фокус. Большой Zoom и масштаб Windows влияют на физический размер изображения; параметры выше указаны в CSS px.

Отключение оформляется через [UI](../../UI/KB/README.md#отключение).
