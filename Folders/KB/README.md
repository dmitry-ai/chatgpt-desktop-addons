# Папки проектов Codex

Модуль добавляет иерархию папок в штатную секцию Projects. Проекты, их ID, каталоги, чаты и штатные действия сохраняются. Элементы проектов остаются у своих React-родителей; модуль задаёт им порядок, отступ и видимость через CSS.

## Управление

- Кнопка папки с плюсом рядом с Projects создаёт корневую папку. Она доступна и при свёрнутой секции.
- Стрелка либо имя папки раскрывает и сворачивает ветку.
- Действия с папкой открываются правым кликом: создание проекта, подпапки, изменение имени, расположения и удаление. Панель кнопок при наведении на папку не появляется.
- «Создать проект…» в действиях папки открывает штатную форму Create project. Успешно созданный местный проект автоматически получает выбранную папку; её предки раскрываются. При отмене формы расположение сбрасывается.
- `F2` на сфокусированной папке переименовывает её, `Insert` создаёт подпапку, `Delete` открывает диалог удаления. Стрелки вправо/влево раскрывают и сворачивают папку.
- Правый клик на проекте открывает «Переместить в папку…», «Новый чат» и доступ к остальным штатным действиям проекта. Кнопки действий у проекта при наведении не появляются.
- «Переместить в папку…» открывает дерево расположений почти во всю высоту окна, включая корень и создание новой папки. При открытии все ветки раскрыты; их можно сворачивать стрелками. Выбранная папка отмечена галочкой, её полный путь показан под деревом, прежняя помечена «Сейчас». Кнопки новой папки, отмены и сохранения собраны внизу. Изменение применяется кнопкой «Сохранить». После сохранения целевая ветка раскрывается и проект становится виден. Привязка сохраняется по точному ключу проекта и синхронизируется между C1/C2.
- Такое же дерево используется для родителя новой или перемещаемой папки. Саму папку и её потомков выбрать в качестве её родителя нельзя. Стрелки вверх/вниз, Home/End перемещают фокус; вправо/влево раскрывают ветки; Enter или пробел выбирают папку, не отправляя форму.
- Заголовок папки можно перетащить на другую папку. Бросок на кнопку папки с плюсом рядом с Projects возвращает папку в корень.
- Меню проекта закрывается по `Esc`, клику снаружи или потере фокуса окна. `Esc` не останавливает ответ агента.
- Всплывающие карточки проектов и чатов при наведении в боковой панели скрыты. Собственные кнопки Folders не создают всплывающие подсказки `title`; названия действий сохранены в `aria-label` и контекстном меню.
- Удаление папки поднимает её непосредственные подпапки и проекты к родителю. Проекты и чаты не удаляются.

Одноимённые папки допускаются в разных ветках. Среди детей одного родителя имена должны быть уникальны без учёта регистра. Циклы запрещены. Если удаление или перенос создаёт конфликт имён, операция отклоняется целиком.

## Данные и профили

С 15 октября 2026 года C1 и C2 используют общий [catalog.json](../../Shared-Projects/code/state/catalog.json).  
В нём находятся проекты, дерево `folders`, общие назначения `projectFolderMap`, соответствия ID двух профилей, очередь и конфликты.  
Прежние `ui-folders.json` в обоих профилях сохранены как исходные данные миграции.

Структура и назначения проектов общие для C1/C2. Состояние раскрытия веток индивидуально для профиля; все его окна получают одинаковое раскрытие. Внутри проекции ключ проекта включает штатный вид и ID контейнера, например `local:project:<UUID>`; общий каталог сопоставляет разные ID C1/C2. Имена проектов для привязки к папкам не используются.

Операции сериализует один фоновый помощник; запись выполняется через временный файл и замену. `.bak` содержит предыдущее состояние. Повреждённый каталог не перезаписывается. Ошибки находятся в `UI/code/ui.log`; для восстановления остановите помощник и исправьте JSON либо проверьте `.bak`.

Управление папками не перемещает рабочие каталоги. Синхронизация штатных местных проектов выполняется отдельным модулем Shared-Projects. Верхняя штатная кнопка создаёт проект в корне, а действие в контекстном меню папки сразу назначает ему эту папку. Привязка использует точный ID из результата native createLocal; одинаковые имена, чужие окна и фоновые синхронизации не используются для угадывания проекта. Общая привязка проецируется на C1/C2, раскрытие ветки меняется только в исходном профиле. После миграции сохранены шесть прежних папок; проекты первоначально оставлены в корне.

Кнопка **⇄** рядом с добавлением папки показывает состояние общего каталога и позволяет разрешать конфликты.  
Подробности, миграция и поведение после обновлений — в [Shared-Projects](../../Shared-Projects/KB/README.md#обычная-работа).

## Проверки

Создание проекта и отмена проверяются в `Folders/code/project-creation.test.mjs`, регистрация ID и раскрытие предков — в `Shared-Projects/code/catalog.test.mjs`. Через CDP 18 октября 2026 года в C1 и C2 проверены открытие штатной формы с выбранной папкой и отмена без изменения списка проектов.

19 октября 2026 года: через меню C1 проект Provision перемещён в Upwork, через меню C2 — в Proposals, затем возвращён через меню C1 в прежнее расположение. Раскрытие веток после проверки восстановлено. Реальные события клавиши Esc через CDP закрывают меню и блокируются до обработчика прерывания композера в обоих профилях. Автотесты меню, раскрытия веток, приоритета Esc и создания проекта: `node --test Folders/code/context-menu.test.mjs Folders/code/project-creation.test.mjs` — 10 пройдено.

Дерево выбора дополнительно проверено через CDP в C1/C2: Provision перемещён в `Upwork / Initial / 2026 / 10`, затем в `Upwork / Proposals / 2026 / 10` и обратно. Проверены сохранение только после подтверждения, отмена, клавиатура, передача выбранного родителя в создание подпапки и исключение собственных потомков. Сценарии и отчёты: `Antigravity/daily/2026/10/18/1 - UI/source/check-codex-picker.mjs` и `check-codex-hover.mjs`. Снимок установленного интерфейса получен через `Page.captureScreenshot` без перезагрузки приложения.

Размер увеличенного дерева проверяется сценарием `check-codex-tall-picker.mjs`: в обоих профилях при высоте окна 666 CSS px дерево занимает 538,55 CSS px (80,86%), видны все 12 папок и корень. Сворачивание ветки не уменьшает область дерева; кнопки остаются в окне; отмена сохраняет прежнее назначение проекта.

Из любого каталога:

```powershell
node 'C:/work/research/provision/code/AI/products/OpenAI/ChatGPT/Desktop/Addons/code/Folders/code/store.test.mjs'
```

Для TAP-отчёта используйте `node --test` с тем же путём. Проверяются циклы, имена, сохранение ID, подъём содержимого удаляемой папки, атомарное редактирование и параллельные записи. Проверка изоляции относится к прежнему универсальному `FolderStore`, который сохранён для совместимости и этих тестов. Общие назначения и проекции C1/C2 проверяются в [catalog.test.mjs](../../Shared-Projects/code/catalog.test.mjs).
