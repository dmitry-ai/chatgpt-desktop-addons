# Чёрно-белая иконка для ChatGPT

В этот каталог помещена официальная монохромная иконка ChatGPT во всех стандартных разрешениях (15 слоёв от 16×16 до 256×256):

* [`ChatGPT.ico`](file:///C:/work/research/provision/code/Software/OpenAI/Codex/daily/2026/10/10/result/ChatGPT.ico) — иконка без ядовито-синей подложки `#3143FF`, содержащая белый логотип на прозрачном фоне.

### Привязка к ярлыку на Рабочем Столе
Ярлык [`ChatGPT.lnk`](file:///C:/Users/dfedi/OneDrive/Desktop/ChatGPT.lnk) настроен на этот файл:
```powershell
IconLocation = "C:\work\research\provision\code\Software\OpenAI\Codex\daily\2026\10\10\result\ChatGPT.ico,0"
```
Файл вынесен за пределы системной папки обновлений `C:\Program Files\WindowsApps`, поэтому при автообновлении ChatGPT из Microsoft Store кастомная иконка не сбросится и не затрётся.
