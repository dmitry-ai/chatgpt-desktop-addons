# ChatGPT Desktop Addons  
Addons and runtime supervisors for OpenAI Codex Desktop (`OpenAI.Codex`) on Windows (`https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/13`).  
`CSS` provides compact sidebar and navigation rail styling (`https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/6`).  
`Folders` provides hierarchical sidebar project folders, context menus, and folder-scoped project creation (`https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/6`).  
`Multi-Account` provides isolated dual-instance profile launching (`C1` and `C2`), AppModel dynamic MSIX package discovery, orphan container cleanup, and lifecycle supervision (`https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/2`, `https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/5`, `https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/8`, `https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/12`, `https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/14`).  
`Shared-Projects` synchronizes workspace projects, folder catalog state, and auto-trust policies across `C1` and `C2` (`https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/7`, `https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/9`).  
`UI` runs the background Chrome DevTools Protocol (`CDP`) injection daemon, runtime policy enforcement, and post-update window recovery (`https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/4`, `https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/6`, `https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/9`, `https://github.com/dmitry-ai/chatgpt-desktop-addons/issues/10`).
